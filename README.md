
# ChildServe - QA Automation Project

## Project Overview
ChildServe is a healthcare application testing portfolio project.

This project demonstrates practical QA skills through manual testing, UI automation, API testing, database validation, and CI/CD.

## Testing Scope
- Manual Testing
- Functional Testing
- UI Automation using Playwright
- API Testing
- Database Testing
- Regression Testing
- Cross-Browser Testing
- Defect Reporting

## Tools and Technologies
- Playwright
- JavaScript
- Node.js
- Postman
- SQL
- Git and GitHub
- Jenkins
